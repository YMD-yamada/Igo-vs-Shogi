# 囲碁 vs 将棋: 非対称バトル（再構築版）

囲碁プレイヤーと将棋プレイヤーが別ルールで同時対戦する、ぷよぷよ対テトリス風の非対称バトルを
TypeScript + React + Vite で 1 から作り直したプロトタイプです。

## 採用構成

- 言語: TypeScript
- UI: React
- ビルド/開発: Vite
- 実行: ブラウザ

## 実装した内容

- 囲碁盤 (9x9)
  - 呼吸点判定と石取り
  - 自殺手禁止
- 将棋盤 (5x5)
  - 玉/金/銀/歩 + 侵入駒の簡易セット
  - 将棋側駒の合法手判定
- ぷよテト風の妨害
  - 囲碁が石を取る: 次の将棋手番で将棋側の駒がランダム消去
  - 将棋が侵入駒を取る: 次の囲碁手番で白石がランダム落下
- 勝利条件
  - 囲碁: 5 捕獲で勝利
  - 将棋: 3 捕獲で勝利

## 起動

```bash
npm install
npm run dev
```

## 構成

- `src/types.ts`: 型定義
- `src/igoEngine.ts`: 囲碁ルール
- `src/shogiEngine.ts`: 将棋ルール
- `src/game.ts`: 対戦統合ロジック
- `src/App.tsx`: UI
