## Full description (JA)

黒白侵攻は、囲碁と将棋が別ルールでぶつかり合う非対称ボードゲームです。

囲碁側は 9×9 で包囲し、将棋側は 5×5 で切り込みます。取った結果が相手の盤へ干渉します。1台での手渡し対戦、CPU 対戦、チュートリアル、ハンデに対応しています。

## Full description (EN)

Kuroshiro is an asymmetric board game where Go and Shogi fight with different rules. Captures create interference on the other board. Play hotseat on one device, vs CPU, with tutorial and handicaps.
