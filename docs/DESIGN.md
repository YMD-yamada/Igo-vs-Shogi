# 黒白侵攻 / Kuroshiro — 設計概要

囲碁プレイヤーと将棋プレイヤーが別ルールで対戦し、捕獲結果を相手盤への干渉として送り合う非対称バトル。

## 盤
- 囲碁: 9×9（黒着手、白は侵食石）
- 将棋: 5×5（王・金・銀・桂・歩、成りなし）

## 干渉（要約）
- 囲碁が白を取る → 圧力 / 侵攻駒投下
- 将棋が侵攻駒を取る → 囲碁盤へ白石ドロップ
- 圧力 ≥ 3 で解放可能

## 勝利
- 囲碁: 白石累計 6 捕獲、または将棋王消滅／合法手なし
- 将棋: 侵攻駒 4 捕獲、または黒石が大きく減少

## モード
- ホットシート（1端末手渡し）
- vs CPU
- オンライン（WebSocket ルーム）

詳細は実装時の設計サブエージェント出力に準拠。定数は `packages/engine/src/types.ts` の `DEFAULT_CONFIG`。
