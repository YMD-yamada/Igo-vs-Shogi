# 黒白侵攻 / Kuroshiro — 一盤戦

囲碁と将棋が **同じ 9×9 盤** で直接ぶつかる非対称バトル。

## 盤
- 共有 9×9
- 下段に将棋陣（桂・銀・金・王・金・銀・桂＋歩）
- 囲碁は空きに黒石を打つ

## 相互作用
- **囲碁**: 駒の呼吸点（隣接空き）を塞いで囲み取り。王捕獲は即勝ち
- **将棋**: 駒を動かして黒石のマスへ進入すると石取り。取った石は歩の持ち駒

## 勝利
- 囲碁: 駒累計 5 捕獲、または王捕獲／将棋合法手なし
- 将棋: 黒石累計 10 捕獲
- ハンデで数値変更可

## モード
- ホットシート / vs CPU / オンライン

定数: `packages/engine/src/types.ts` の `DEFAULT_CONFIG`
