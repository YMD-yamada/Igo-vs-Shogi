# 黒白侵攻 / Kuroshiro — 一盤戦

囲碁と将棋が **同じ 9×9 盤** で直接ぶつかる非対称バトル。

## 盤
- 共有 9×9
- 下段に将棋陣（銀・王・銀／桂／金／歩）
- 囲碁は空きに黒石を打つ
- 王に直交連結した駒は呼吸点共有。切れた駒はソロ

## 相互作用
- **囲碁**: 駒の呼吸点を塞いで囲み取り。王捕獲は即勝ち
- **将棋**: 黒石のマスへ進入で石取り。直後の石は歩にならない。桂は石を取れない

## 勝利（互角）
- 囲碁: 駒累計 2 捕獲、または王捕獲／将棋合法手なし
- 将棋: 黒石累計 6 捕獲
- ハンデで数値変更可（`packages/engine/src/handicaps.ts`）

## モード
- ホットシート / vs CPU（どちら側でも可） / オンライン

## ログと長期改善
- 終局ごとに軽量 MatchLog を保存（`docs/FEEDBACK_LOOP.md`）
- `npm run analyze:logs` で集計、「フィードバック適用」で調整サイクル

定数: `packages/engine/src/types.ts` の `DEFAULT_CONFIG`
